# [公路桥梁技术状况评定系统]([tianpengwan/qiaoliangJTG-T-5230-2026: 桥梁技术状况评定系统 基于JTG/T 5230—2026可一键生成报告](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026))

依据 **《公路桥梁技术状况评定标准》JTG/T 5230—2026** 开发的桥梁技术状况评定与报告导出系统。

> 2026-08-26 发布，2026-11-01 实施。原 JTG/T H21—2011 的 BDCI/SPCI/SBCI/Dr 评分体系已被本标准替代，本项目已按新标准重构评定模型、缺损库、界面和报告。

---

## 一、新标准评定逻辑

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E4%B8%80%E6%96%B0%E6%A0%87%E5%87%86%E8%AF%84%E5%AE%9A%E9%80%BB%E8%BE%91)

```
构件耐久性缺损（第 4 章）
构件结构性缺损（第 5~13 章）
        ↓  取最大标度
缺损状况 EDI（0~3）
        +
功能状况 EFI（第 14 章，0~2）
        +
影响状况 EAI（第 15 章，-1/0/1）
        ↓
构件技术状况 ECI = EDI + EFI + EAI（≥5 取 5）     式(3.2.5)
        ↓
构件等级 ECL：ECI≤1 为 1 类，≤2 为 2 类，≤3 为 3 类，≤4 为 4 类，>4 为 5 类
        ↓ 同一部件取最差构件 CI(j)
桥跨 BSCI = 100 − Σ CI(j)·ω·γ/5                  式(3.3.1)
        ↓
全桥 BCI（第 3.4 节；多跨等级不一致按式 3.4.3）
        ↓
命中 16 条单项控制指标任一 → 全桥直接 5 类（第 3.4.5 条）
```

* **桥型与部件权重**：按附录 B 表 B.2.2\~B.6.3，覆盖梁桥、拱桥、组合体系拱桥、悬索桥、斜拉桥共 **21 种结构形式**。
* **缺损指标**：第 4~~15 章共 **138 张评定表**，包含指标名称、0~~3 标度及文字描述。
* **未设置构件**：不计入计算，权重在部位内按比例重新归一。
* **未录入缺损的构件**：按完好（ECI=0）参与评定。
* **主要构件 4/5 类且影响安全**：可按第 3.3.3 条以最差构件等级评定桥跨，BSCI 取等级上限（4 类 60、5 类 40）。

## 二、功能

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E4%BA%8C%E5%8A%9F%E8%83%BD)

* 桥梁台账、多跨（评定单元）管理，自动生成附录 B 规定的构件体系
* 按部位（桥面系/上部结构/下部结构/附属构造）逐构件录入耐久性、结构性、功能、影响记录
* 实时计算 EDI/EFI/EAI/ECI/ECL、BSCI、BCI
* 16 条 5 类单项控制指标检查
* 照片上传；可选 AI 视觉识别（OpenAI 兼容接口），辅助选择指标与标度
* Excel / Word 评定报告导出（含概况、构件汇总、缺损记录、结果、5 类检查）
* 移动端优先界面，支持手机浏览器 / PWA / Android APP
* 账号密码登录（网页、PWA、APP 统一鉴权），登录有效期可配置
* Docker 部署，适配飞牛 NAS

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E4%B8%89%E6%9C%AC%E5%9C%B0%E8%BF%90%E8%A1%8C)

## 四、目录结构

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E5%9B%9B%E7%9B%AE%E5%BD%95%E7%BB%93%E6%9E%84)


## 五、Android APP

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E4%BA%94android-app)

前端已通过 Capacitor 打包为 Android 工程：

```shell
npm install
npm run mobile:sync          # 同步 public → www → android
npm run mobile:open          # 用 Android Studio 打开
npm run mobile:apk           # 命令行构建 debug APK
```

已构建好的安装包：`deploy/apk/桥梁评定.apk`（包名 `com.qiaoliang.jtg5230`，最低 Android 7.0）。 重新构建时输出在 `android/app/build/outputs/apk/debug/app-debug.apk`。

安装后首次打开填写飞牛 NAS 地址，并输入服务器上配置的账号密码（默认 `admin` / `qiaoliang@2026`，请务必修改）。 详细安装与连接说明见 [deploy/飞牛NAS部署教程.md](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026/blob/main/deploy/%E9%A3%9E%E7%89%9BNAS%E9%83%A8%E7%BD%B2%E6%95%99%E7%A8%8B.md)。

## 六、Docker / 飞牛 NAS

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E5%85%ADdocker--%E9%A3%9E%E7%89%9B-nas)

```shell
# 在线构建
docker compose up -d --build

# 离线镜像（在电脑上构建并导出，NAS 导入）
powershell -ExecutionPolicy Bypass -File .\deploy\scripts\build-and-save-image.ps1

# 仅下载基础镜像（国内网络，自动切换镜像源）
bash deploy/scripts/prepare-base-image.sh
```

默认访问端口 `5230`，数据持久化在 `data/`、`uploads/`、`exports/`。

### 登录账号

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E7%99%BB%E5%BD%95%E8%B4%A6%E5%8F%B7)

网页端、PWA 和手机 APP 都必须先登录，账号在 `.env` 中配置：


| 变量             | 默认             | 说明                                                     |
| ---------------- | ---------------- | -------------------------------------------------------- |
| `AUTH_USER`      | `admin`          | 登录账号                                                 |
| `AUTH_PASS`      | `qiaoliang@2026` | 登录密码，部署后请立即修改                               |
| `AUTH_SECRET`    | 空               | 令牌签名密钥，建议填随机字符串；更换后所有设备需重新登录 |
| `AUTH_TTL_HOURS` | `720`            | 登录有效期（小时）                                       |

修改 `.env` 后执行 `docker compose up -d` 生效，无需重建镜像。同一 IP 连续输错 8 次密码将锁定 5 分钟。

离线镜像 tar 需在装有 Docker 的电脑上由脚本生成（`deploy/offline/bridge-assessment-5230.tar`）， 脚本已包含 `docker build` 与 `docker save`，生成后拷贝到飞牛执行 `docker load` 即可，NAS 全程不需要外网。

完整步骤（含飞牛图形界面、离线导入、备份、升级、常见问题）见 **[deploy/飞牛NAS部署教程.md](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026/blob/main/deploy/%E9%A3%9E%E7%89%9BNAS%E9%83%A8%E7%BD%B2%E6%95%99%E7%A8%8B.md)**。

## 七、标准数据说明

[](https://github.com/tianpengwan/qiaoliangJTG-T-5230-2026#%E4%B8%83%E6%A0%87%E5%87%86%E6%95%B0%E6%8D%AE%E8%AF%B4%E6%98%8E)

`std5230_data.js` 中的评定表、标度描述和附录 B 参数，依据公开的 JTG/T 5230—2026 标准文本整理。正式用于检测报告、行政认定或司法用途前，请以交通运输部正式出版的标准文本为准，并由具备资质的检测人员复核签认。

系统计算结果为辅助工具输出，不替代注册检测工程师的技术判断。
